개인정보 처리방침

수집하는 정보

Markdown Viewer 확장 프로그램은 어떠한 개인정보나 사용자 데이터도 수집, 저장, 전송하지 않습니다.

확장 프로그램이 하는 일

  • 주소가 .md 등 마크다운 확장자로 끝나는 페이지에서만 동작하며, 그 페이지의 마크다운 텍스트를 읽어 브라우저 안에서 화면에 그립니다.
  • 확장 전용 뷰어 페이지에서 사용자가 직접 고르거나 끌어다 놓은 파일을 읽어 표시합니다. 파일 내용은 브라우저 밖으로 나가지 않습니다.
  • 테마·글자 크기 등 표시 설정과 문서별 읽던 위치만 chrome.storage에 저장하며, 이 값은 사용자의 브라우저 안에만 남습니다.
  • 웹사이트의 .md 파일 표시는 사용자가 팝업에서 직접 켠 경우에만 동작하며, 이때 브라우저가 사이트 접근 권한을 묻습니다.

외부 전송

분석 도구, 광고, 외부 서버, CDN을 사용하지 않습니다. 필요한 라이브러리는 모두 확장 패키지에 포함되어 있습니다. 문서에 포함된 이미지나 링크는 사용자가 연 문서 자체의 내용이며, 브라우저가 일반 웹페이지와 같은 방식으로 불러옵니다. 단, 사용자가 "HTML로 내보내기"로 저장한 파일을 나중에 열면 수식 글꼴을 공개 CDN(cdn.jsdelivr.net)에서 불러옵니다. 확장 프로그램 자체는 이 요청을 보내지 않습니다.

제3자 제공

수집하는 데이터가 없으므로 제3자에게 제공하거나 판매하는 데이터도 없습니다.

Privacy Policy

Data collection

The Markdown Viewer extension does not collect, store, or transmit any personal information or user data.

What the extension does

  • It runs only on pages whose URL ends with a Markdown extension such as .md, reads the Markdown text of that page, and renders it inside your browser.
  • On the extension's own viewer page, it reads files you explicitly pick or drop. File contents never leave your browser.
  • Only display preferences (theme, font size, etc.) and the last reading position per document are saved with chrome.storage, and they stay in your browser.
  • Rendering .md files on websites works only after you turn it on in the popup, at which point the browser asks for site access.

Network

No analytics, ads, remote servers, or CDNs are used. All libraries are bundled in the extension package. Images or links inside a document belong to the document you opened and are loaded by the browser as on any web page. Note: a file you save with "Export as HTML" loads math fonts from a public CDN (cdn.jsdelivr.net) when you later open it; the extension itself never makes that request.

Third parties

Because no data is collected, no data is shared with or sold to third parties.
